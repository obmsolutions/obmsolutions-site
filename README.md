## Publicação no GitHub Pages

1. Crie um repositório para o site (ex.: `obmsolutions-site`).
2. Envie todo o conteúdo deste pacote para a raiz do repositório.
3. No GitHub, abra `Settings > Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.
7. Depois da validação visual, configure o domínio personalizado em `Settings > Pages > Custom domain`.
8. Só então configure o DNS no Registro.br.
